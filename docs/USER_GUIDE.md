# SysteMIC — User Guide (English)

Quick practical guide for church leaders and administrators using the SysteMIC backoffice app.

**Full reference:** [DOCUMENTATION.md](DOCUMENTATION.md)

---

## 1. Sign in

1. Open the app (mobile or browser/desktop).
2. Enter your **email** and **password**.
3. Tap **Sign in**.

If you received a default password (`Password123`), you must **change it** before continuing.

**Forgot password?** Use the link on the login screen and follow the email instructions.

---

## 2. Choose your language

**Settings → Language** → English, French, or Spanish.

The interface updates immediately.

---

## 3. Dashboard (Home)

The home screen shows:

- Upcoming training sessions and events
- Open tasks
- Birthdays this month
- Quick links to main modules

On **desktop**, you also see attendance charts and tables (events, teachings, newcomers).

**Tip:** Pull down to refresh on mobile.

---

## 4. Members

### Add a member

1. **Members → Add** (+).
2. Fill **first name**, **last name**, and **birthday** (required).
3. Add phone, email, address, role, and departments as needed.
4. If they are a **newcomer**, check **New comer** and set intention:
   - *Wants to stay* — integration track
   - *Does not know yet* — undecided
   - *Just passing* — **cannot** be saved as member; create a **Visitor** instead
5. Save.

### Member accounts (admin)

**Settings → Member accounts** — create a login for a member who has an email. They start with view-only access until you adjust **Leader access**.

---

## 5. Church attendance

### Create a service

1. **Church attendance →** open list or mark attendance.
2. Pick a **date** (any day of the week).
3. Enter a **service name** (required), e.g. “Sunday Morning”, “Wednesday Prayer”, “Evening Service”.
4. You can have **several services on the same day** with different names.

### Mark attendance

1. Open the service.
2. For each member, set:
   - **Onsite** — present in person
   - **Online** — joined remotely
   - **Absent** — did not attend
3. Optional **observation** per member.
4. Use **bulk actions** or filters (children, absent, etc.).
5. **Save**.

### Visitors during a service

Use **Add visitor** on the attendance screen to log someone who is not yet a member.

### Reports

From the attendance list: **Generate PDF** for a date range or absentees for one service.

---

## 6. Sunday school

For **children only** (ages 0–12):

1. **Sunday school →** pick a session date.
2. Mark each child present.
3. Export PDF if needed.

---

## 7. Visitors

1. **Visitors → Add**.
2. Enter name, visit date, optional service link, phone, notes.
3. **Convert to member** when they decide to join (if permitted).

---

## 8. Departments

1. **Departments** — open a department.
2. **Overview:** documents, members, roles (leader / subleader / member).
3. **Tasks:** department task workspace.
4. **Reports:** written reports + PDF export.

**Media Team:** use **Service schedule** to assign projection, camera, photo roles per date.

---

## 9. Tasks

Open **Tasks** from the sidebar (desktop) or dashboard.

| View | Use for |
|------|---------|
| **Projects** | Tasks grouped by project |
| **All** | Full table with inline edit |
| **Board** | Kanban by status |
| **Timeline** | Schedule overview |
| **Penalties** | Unpaid balances and payments |

### Create a task

1. **Add task** — title, department or member, due date, priority, project, tags.
2. Assign members.
3. Save.

### Tags

**Manage tags** — create colored labels per department. Pick a color when creating a tag.

### Reminders

From task detail or list: send a **reminder** to assignees (push + in-app notification).

### Penalties

Overdue tasks may accrue daily penalties. Members above the balance threshold cannot receive new assignments until payments are recorded under **Penalties** view.

---

## 10. Teachings

1. **Teachings → Add** — title, date, speaker, notes.
2. Saving creates **Media Team tasks** automatically (video edits).
3. On teaching detail: manage **listeners** or **sync from attendance** for that date.

---

## 11. Trainings (classes)

1. Create a **training** and enroll members.
2. **Generate sessions** (weekly schedule).
3. Open a session → **Take attendance**.
4. View reports from **Reports → Trainings**.

---

## 12. Events

1. **Events → Add** — title, date, location.
2. On event detail: **Registrations** — register members or guests.

---

## 13. Finance (authorized users only)

**Finance** tab appears for admins and Finance department leaders.

1. **Add giving** — giver, amount, type (receiving/expense), category (tithe, offering, etc.).
2. Generate **PDF report** for a period.

---

## 14. Chat (announcements)

**Chat** shows announcements (not private messaging).

**Leaders/admins:** create global, department, or targeted announcements.

---

## 15. Notifications

Bell icon or **Notifications** in sidebar — task assignments, reminders, birthdays, announcements.

Enable push on mobile via device settings and app notification preference in **Settings**.

---

## 16. Reports

**Reports** hub:

- Members, trainings, newcomers (weekly/monthly/yearly/custom)
- Individual member or training reports
- PDF exports from attendance, visitors, finance, departments

---

## 17. Settings (admin)

| Item | Purpose |
|------|---------|
| **Leader access** | Per-user view/create/edit/delete per module |
| **Member accounts** | Create logins |
| **Birthday notifications** | Church-wide birthday messages |
| **Export / import** | JSON backup and restore |
| **Sync users & members** | Align auth with member records |

---

## 18. Desktop vs mobile

| Mobile | Desktop (wide screen) |
|--------|---------------------|
| Bottom nav: Home, Members, Finance*, Chat, Settings | Left sidebar with all modules |
| Dashboard quick actions | Tables and charts on home |
| Full-screen pages | List + detail stack |

\*Finance tab only if authorized.

---

## 19. Common issues

| Problem | What to do |
|---------|------------|
| Cannot see a module | Ask admin to grant **Leader access** for that feature |
| Cannot assign tasks to someone | Check **penalty balance** — may be blocked |
| “Just passing” newcomer | Create as **Visitor**, not member |
| Service name rejected | Name must be unique for that date |
| Session expired | Sign in again |

---

## 20. Getting help

Contact your church **system administrator** for access, training, or data questions.
