# SysteMIC — Guide utilisateur (Français)

Guide pratique pour les responsables et administrateurs de l’application backoffice SysteMIC.

**Documentation complète :** [DOCUMENTATION.fr.md](DOCUMENTATION.fr.md)

---

## 1. Connexion

1. Ouvrez l’application (mobile ou navigateur/bureau).
2. Saisissez votre **e-mail** et votre **mot de passe**.
3. Appuyez sur **Se connecter**.

Si vous avez reçu le mot de passe par défaut (`Password123`), vous devez le **modifier** avant de continuer.

**Mot de passe oublié ?** Utilisez le lien sur l’écran de connexion et suivez les instructions reçues par e-mail.

---

## 2. Choisir la langue

**Paramètres → Langue** → Anglais, Français ou Espagnol.

L’interface se met à jour immédiatement.

---

## 3. Tableau de bord (Accueil)

L’écran d’accueil affiche :

- Les prochaines sessions de formation et événements
- Les tâches ouvertes
- Les anniversaires du mois
- Des raccourcis vers les modules principaux

Sur **ordinateur**, vous voyez aussi des graphiques et tableaux (événements, enseignements, nouveaux venus).

**Astuce :** Tirez vers le bas pour actualiser sur mobile.

---

## 4. Membres

### Ajouter un membre

1. **Membres → Ajouter** (+).
2. Renseignez **prénom**, **nom** et **date de naissance** (obligatoires).
3. Ajoutez téléphone, e-mail, adresse, rôle et départements si besoin.
4. Si c’est un **nouveau venu**, cochez **Nouveau venu** et l’intention :
   - *Souhaite rester* — parcours d’intégration
   - *Ne sait pas encore* — indécis
   - *De passage* — **ne peut pas** être enregistré comme membre ; créez un **Visiteur**
5. Enregistrez.

### Comptes membres (admin)

**Paramètres → Comptes membres** — créez une connexion pour un membre ayant un e-mail. L’accès est en lecture seule jusqu’à configuration des **droits responsables**.

---

## 5. Présence aux cultes

### Créer un culte / service

1. **Présence culte →** liste ou marquage.
2. Choisissez une **date** (n’importe quel jour).
3. Saisissez un **nom de service** (obligatoire), ex. « Culte du matin », « Prière du mercredi », « Culte du soir ».
4. Vous pouvez avoir **plusieurs services le même jour** avec des noms différents.

### Marquer la présence

1. Ouvrez le service.
2. Pour chaque membre :
   - **Sur place** — présent physiquement
   - **En ligne** — à distance
   - **Absent** — n’a pas participé
3. **Observation** facultative par membre.
4. Utilisez les actions groupées ou les filtres (enfants, absents, etc.).
5. **Enregistrez**.

### Visiteurs pendant un culte

**Ajouter un visiteur** sur l’écran de présence pour une personne pas encore membre.

### Rapports

Depuis la liste : **Générer un PDF** sur une période ou liste des absents pour un service.

---

## 6. École du dimanche

Pour les **enfants uniquement** (0–12 ans) :

1. **École du dimanche →** choisissez une date de session.
2. Marquez chaque enfant présent.
3. Exportez un PDF si nécessaire.

---

## 7. Visiteurs

1. **Visiteurs → Ajouter**.
2. Nom, date de visite, service optionnel, téléphone, notes.
3. **Convertir en membre** lorsqu’ils souhaitent rejoindre l’église (si autorisé).

---

## 8. Départements

1. **Départements** — ouvrez un département.
2. **Vue d’ensemble :** documents, membres, rôles (responsable / adjoint / membre).
3. **Tâches :** espace de travail du département.
4. **Rapports :** rapports rédigés + export PDF.

**Équipe média :** **Planning des services** pour assigner projection, caméra, photo par date.

---

## 9. Tâches

Ouvrez **Tâches** depuis la barre latérale (bureau) ou le tableau de bord.

| Vue | Usage |
|-----|--------|
| **Projets** | Tâches par projet |
| **Toutes** | Tableau avec édition en ligne |
| **Tableau** | Kanban par statut |
| **Chronologie** | Vue planning |
| **Pénalités** | Soldes et paiements |

### Créer une tâche

1. **Ajouter une tâche** — titre, département ou membre, échéance, priorité, projet, étiquettes.
2. Assignez des membres.
3. Enregistrez.

### Étiquettes

**Gérer les étiquettes** — créez des libellés colorés par département. Choisissez une couleur à la création.

### Rappels

Depuis le détail ou la liste : envoyez un **rappel** aux assignés (notification push + dans l’app).

### Pénalités

Les tâches en retard peuvent générer des pénalités journalières. Au-delà du seuil, un membre ne peut plus recevoir de nouvelles tâches jusqu’à enregistrement d’un paiement dans la vue **Pénalités**.

---

## 10. Enseignements

1. **Enseignements → Ajouter** — titre, date, orateur, notes.
2. L’enregistrement crée automatiquement des **tâches Équipe média** (montages vidéo).
3. Sur le détail : gérez les **auditeurs** ou **synchronisez depuis la présence** à cette date.

---

## 11. Formations

1. Créez une **formation** et inscrivez des membres.
2. **Générez les sessions** (planning hebdomadaire).
3. Ouvrez une session → **Prendre la présence**.
4. Consultez les rapports via **Rapports → Formations**.

---

## 12. Événements

1. **Événements → Ajouter** — titre, date, lieu.
2. Sur le détail : **Inscriptions** — inscrire membres ou invités.

---

## 13. Finances (utilisateurs autorisés)

L’onglet **Finances** apparaît pour les admins et responsables du département Finance.

1. **Ajouter une offrande** — donateur, montant, type (recette/dépense), catégorie (dîme, offrande, etc.).
2. **Générez un rapport PDF** sur une période.

---

## 14. Chat (annonces)

**Chat** affiche les annonces (pas de messagerie privée).

**Responsables/admins :** créez des annonces globales, par département ou ciblées.

---

## 15. Notifications

Icône cloche ou **Notifications** dans la barre latérale — assignations, rappels, anniversaires, annonces.

Activez les notifications push sur mobile via les paramètres de l’appareil et **Paramètres** de l’application.

---

## 16. Rapports

Hub **Rapports** :

- Membres, formations, nouveaux venus (hebdo/mensuel/annuel/personnalisé)
- Rapports individuels membre ou formation
- Exports PDF depuis présence, visiteurs, finances, départements

---

## 17. Paramètres (admin)

| Élément | Rôle |
|---------|------|
| **Droits responsables** | Voir/créer/modifier/supprimer par module |
| **Comptes membres** | Créer des connexions |
| **Notifications anniversaires** | Messages d’anniversaire |
| **Exporter / importer** | Sauvegarde et restauration JSON |
| **Synchroniser utilisateurs** | Aligner auth et membres |

---

## 18. Bureau vs mobile

| Mobile | Bureau (grand écran) |
|--------|----------------------|
| Nav. bas : Accueil, Membres, Finances*, Chat, Paramètres | Barre latérale avec tous les modules |
| Actions rapides tableau de bord | Tableaux et graphiques |
| Pages plein écran | Liste + détail empilés |

\*Finances si autorisé.

---

## 19. Problèmes courants

| Problème | Solution |
|----------|----------|
| Module invisible | Demander les **droits responsables** à l’admin |
| Impossible d’assigner une tâche | Vérifier le **solde de pénalités** |
| Nouveau venu « de passage » | Créer un **Visiteur** |
| Nom de service refusé | Le nom doit être unique pour cette date |
| Session expirée | Se reconnecter |

---

Contactez l’**administrateur système** de votre église pour l’accès, la formation ou les données.
